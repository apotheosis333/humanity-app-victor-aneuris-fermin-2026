# Google Play Listing Assets

These assets support the default English (United States) Google Play listing.

- `app-icon-512.png`: 512 x 512 app icon.
- `feature-graphic-1024x500.jpg`: 1024 x 500 feature graphic.
- `phone/01-home.png`: Home screen.
- `phone/02-explore.png`: Explore screen.
- `phone/03-countries.png`: Country list.
- `phone/04-country-detail.png`: Country detail.

The phone screenshots were captured from the real Android app without private
profile data. The assets were uploaded to the Play Console default listing as a
draft on 2026-07-30. They remain subject to founder/designer approval before a
production submission.
