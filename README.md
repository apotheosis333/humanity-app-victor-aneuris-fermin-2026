# HuMANity

**HuMANity** is a global social platform designed to connect people across the world, promote unity, and display active users on a live global map.

The purpose of HuMANity is simple: to remind people that no matter where they are from, what language they speak, or what background they come from, they are part of one human family.

## 🌍 Vision

HuMANity aims to become a digital bridge for global connection. The platform is built around the idea that technology should not only entertain people, but also bring them closer together, encourage meaningful communication, and help create a more unified world.

## ✨ What HuMANity Does

HuMANity allows users to create personal profiles, connect with others, and visually see the global community through an interactive world map. When users sign up, they can appear as part of the platform’s global active-user network, showing how people from different regions are joining together in real time.

## 🚀 Core Features

* User sign-up and personal profiles
* Profile picture upload
* Ability to add a song to a profile through Apple Music or Spotify lookup
* Global active-user map
* Public user presence by region
* Social connection tools
* Clean and modern user interface
* Mission-focused design centered on unity, humanity, and global connection

## 🎯 Mission

The mission of HuMANity is to use technology as a tool for connection, peace, and understanding. Instead of creating another ordinary social app, HuMANity is being built to represent something bigger: a platform where users can feel seen, connected, and part of a worldwide movement.

## 🧭 What I Hope to Accomplish

Through HuMANity, I hope to create a platform that helps people feel less divided and more connected. The goal is to build a digital space where humanity is visually represented on a global scale, showing active users around the world and encouraging people to recognize each other as part of one shared human story.

## 📍 Global Active Users Feature

One of the main features of HuMANity is the **Active Users Global Map**. This feature is designed to show where users are joining from around the world. The goal is not to expose private personal locations, but to create a visual representation of global participation and unity.

Users may be shown by general region, country, or city-level approximation depending on privacy settings and implementation.

## 🔐 Privacy First

HuMANity should be built with user privacy in mind. Any location-based feature should avoid displaying exact personal addresses or precise coordinates. The platform should prioritize safety, consent, and responsible data handling.

## API Configuration

Local web development can leave `VITE_API_BASE_URL` empty so frontend requests continue to use same-origin `/api` paths.

Mobile or Capacitor builds must set `VITE_API_BASE_URL` to the deployed backend origin, for example `https://api.example.com`. The frontend will then call paths such as `/api/me/profile` through that backend origin.

Only client-safe public values belong in `VITE_` variables. Private secrets such as database URLs, Clerk secret keys, OpenAI keys, and storage credentials must stay in backend/deployment environment settings and must never be committed.
